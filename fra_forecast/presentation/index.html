The learned part

Learn the error.
Keep the weather model.

Separate regressors learn the difference between observed and forecast east–west wind, north–south wind, and gusts. The predicted error is added to ICON-EU.

We compare Ridge regression, gradient boosting and an equal blend with raw ICON-EU. Observation persistence is a reference. Validation chooses the model; the test set does not set its weights.

The uncertainty estimate

A separate calibration period records the remaining errors. For each future hour, we sample 256 joint wind-and-gust errors from the matching forecast-lead band.

We add each error triple to the forecast and apply the Runway 18 wind limits. The fraction that passes is a provisional weather-usability probability.

The challenge rules behind the baseline
  • Landing tailwind ≥10 kt forces an immediate direction change.
  • Departure tailwind ≥15 kt prevents departure, including on RWY18.
  • Crosswind >40 kt, including gusts, prevents runway use.
  • Smaller tailwind is tolerated for up to 30 minutes; persistence >30 minutes changes direction.

Hourly forecasts cannot resolve exact 30-minute persistence. Gust direction is approximated by mean wind direction when unavailable.

Model inputs, source data and reproducibility

Inputs: forecast u/v wind components, gust and its missing indicator, model lead time, and sine/cosine of UTC hour and day of year. Ridge uses train-only imputation and scaling with alpha = 1. No driver importance ranking is claimed.

Forecasts: Open-Meteo explicit ICON-EU runs. Reference observations: DWD station 01420. METAR and current operations are separate live context, not future training inputs.

This page describes the comparison pipeline at /api/forecast-comparison. The original /api/forecast ML block retains its separate validation choice. GFS is an unranked live comparison; the optional AI coordinator explains results and cannot set numeric weights.
